# ComfyUI-MiniMaxH3-Cache
A better cache node for MiniMax H3

**[[📃中文版](./README_zh.md)]** 

## Installation
```bash
cd ComfyUI/custom_nodes
git clone https://github.com/lihaoyun6/ComfyUI-MiniMaxH3-Cache.git
```

## Usage
Use it just like you would use EasyCache.  
⚠️  
**This node patches ComfyUI core files.**  
**If you encounter generation issues, remove this extensions and restart ComfyUI.**
