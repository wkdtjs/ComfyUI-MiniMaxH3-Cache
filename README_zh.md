# ComfyUI-MiniMaxH3-Cache
专为 MiniMax H3 优化的缓存加速节点

**[[📃English](./README.md)]**     

## 安装
```bash
cd ComfyUI/custom_nodes
git clone https://github.com/lihaoyun6/ComfyUI-MiniMaxH3-Cache.git
```

## 使用方法
像使用 EasyCache 节点一样使用即可.  
⚠️ **本插件会对ComfyUI核心代码进行修补, 若出现无法正常生成的情况, 请删除本插件并重启ComfyUI**
